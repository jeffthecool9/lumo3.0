# Guided Workspace

The authenticated workspace presents an optional welcome dialog on its first ready visit. A Tutorial tab remains available permanently, and a header shortcut opens it from every workspace view. Existing deep links and prompt drafts are preserved.

Setup order: Business details, Products & prices, Sales flow, Practice chat. Navigation separates setup tasks, daily sales work, and account controls. Page headings match these navigation labels. Approving a sales flow opens practice chat directly.

Readiness is derived from saved business details, at least one approved catalogue offer, an approved flow, and a successful practice exchange against an approved plan. Practice is tracked per plan ID so a new unapproved draft is never marked tested merely because an earlier version was tested. Customer channels stay explicitly unactivated.

Welcome dismissal and practice history are browser-local preferences scoped by workspace ID. They are convenience indicators, not billing, authentication or AI access entitlements. They may reset on another browser or after browser data is cleared. The server remains authoritative for every paid AI action.

Local UI verification uses labelled sample records. Automatic welcome requires a ready authenticated workspace; it does not bypass missing database configuration. Tutorial progress is setup readiness, not proof of production messaging, AI accuracy or customer delivery.
